# raw/slack-exports/

Exported Slack conversations — channels or DMs containing decisions, discussions, or context worth preserving.

**Where to export from:**
- Workspace-wide export (needs admin access): Slack → Settings & administration → Workspace settings → Import/Export Data → Export
- Single conversation: some workspaces allow exporting a channel's history via a Slack export app, or manually copying/pasting key threads into a text file if you don't have export permissions

Drop the exported files (JSON export folders or plain-text thread copies) here.
