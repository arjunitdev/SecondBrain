# raw/claude-exports/

Exported conversations from Claude (claude.ai or Claude Code sessions) that contain useful context, decisions, or knowledge worth folding into the wiki.

**Where to export from:**
- claude.ai → Settings → Account → "Export data" (produces a full data export including `conversations.json`)
- Individual conversation → use the "..." menu on a conversation → Export/Copy, if available

Drop the exported files or extracted conversation text here as-is.
