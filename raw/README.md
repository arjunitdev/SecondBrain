# raw/

This is **your** space. Everything in here is a source document you brought in from somewhere else — exported chats, notes, documents, etc.

Rules:
- Nothing in `raw/` is ever edited, rewritten, or deleted by Claude. It's the ground truth.
- Organize your imports into the subfolder that matches where they came from (see each subfolder's README for what belongs there and how to export it).
- If a source doesn't fit an existing subfolder, create a new one rather than dumping it loose in `raw/`.

Processed, synthesized, and cross-referenced versions of this material live in `../wiki/`, not here.
