Append the following note to `wiki/log.md` as a new timestamped entry: $ARGUMENTS

1. Add one entry at the end of `wiki/log.md` with the current date/time and the note text, verbatim, do not edit or paraphrase past entries.
2. Check whether the note mentions a project, person, or concept that already has a page in `wiki/`. If it does, update that page (e.g. adding the relevant detail, updating `last-updated`) to reflect the note.
3. If the note mentions something that does not yet have a wiki page, do not create a new page for it — logging the note is enough. Page creation happens via `/ingest` or explicit request, not automatically here.
